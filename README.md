# Nijar — Frontend

معرض وورشة أخشاب | Wood Workshop & Gallery

## Tech Stack
- Next.js 16 (App Router)
- React 19 + TypeScript
- MUI v9 (RTL)
- Axios + Cairo Font

## Getting Started

```bash
npm install
npm run dev
```

## Environment Variables

```env
NEXT_PUBLIC_API_URL=http://localhost:5000/api/v1
```
